# 邦布小光

“根本没有这种邦布！？”一只黄身黑发、红眼睛的小邦布，胸前系着蓝色蝴蝶结。它平时萌萌地站着，认真起来会变身成白发白衣、红色点缀的持剑形态。

## 动作表现

- **待机**：保持自然站立；受到点击时挥手示意。
- **移动**：以原本的黑发形态向左右移动。
- **工作**：已经完成变身，持剑摆出冲锋姿态。
- **思考**：尚未变身，持剑认真思索。
- **等待**：闭眼舔着彩色棒棒糖。
- **完成**：严格保留参考图中的吐舌笑容、持玫瑰动作和姿态。
- **失败**：以原本形态露出困惑表情。

其余视线方向也采用日常的黄身黑发形态。整体使用透明背景、无文字设计，让角色在桌宠尺寸下仍有清晰轮廓。
