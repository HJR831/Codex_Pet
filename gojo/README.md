# 五条悟 Codex 桌宠

这是一个 Codex v2 自定义桌宠安装包，角色造型来自五条悟：白色尖发、黑色眼罩、紫黑色高领制服。

## 安装

将整个 `gojo` 文件夹复制到 Codex 的个人宠物目录：

```text
%USERPROFILE%\\.codex\\pets\\gojo
```

目录中必须同时保留：

- `pet.json`
- `spritesheet.webp`

复制完成后重启或刷新 Codex，在宠物选择中选择“五条悟”。

## 动作

图集包含 Codex v2 标准动作：待机、左右移动、挥手、跳跃、问题提醒、等待输入、敲代码、歪头思考，以及 16 个连续转头方向。

`extras/sleeping.webp` 和 `extras/sleeping.gif` 是额外的趴睡动画预览。标准 v2 图集没有独立的 sleeping 状态，因此它不会自动替换标准状态；需要自定义集成时可单独使用。

## 文件说明

- `pet.json`：宠物名称、描述和 v2 图集声明。
- `spritesheet.webp`：1536×2288 的透明 RGBA 动画图集，8 列 × 11 行，每格 192×208。
- `extras/`：额外睡觉动画。
